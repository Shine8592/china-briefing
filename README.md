# 📰 China Briefing — 多尺度中文资讯简报 v4 · 四引擎协作版

> **版本：** v4.0（2026-11-18）——从"单引擎/线性降级"升级为"四引擎按环节协作、关键事实双源交叉"。

多尺度中文资讯简报技能：从一条街道到全球，任意地理范围都能生成一份结构化、带来源、有深度点评的简报。

## ✨ v4.0 核心：四引擎协作矩阵

**核心理念**：四家检索引擎强弱互补、不在同一条线上，**不排队等前一个挂了才降级**，而是按环节各守岗位、关键事实由两家不同来源交叉印证。同时**不是每条都调四个**——按场景精准调用，控成本、控速度。

| 环节 | 主用 | 辅用 | 说明 |
|---|---|---|---|
| 中文发现 | **wb2a** | Exa | wb2a 免费、权威中文源、长正文；Exa 补语义检索 |
| 国际/英文发现 | **Exa** | Tavily | 两家不同源，天然满足"≥2 家通讯社"门禁 |
| 中文视角补充 | wb2a | — | 英文查询 wb2a 只回中文转述，仅作补充、不作国际主源 |
| 正文抓取 | **wb2a `--fetch`** | Exa `--url` → Firecrawl | 免费先上；Exa \$1/1k 页；Firecrawl 仅硬反爬、403/404 也扣费 |
| 关键事实交叉验证 | 任意两家不同源 | — | 同一事实两家原文印证才进头条；单源标注"待交叉核实" |

**四引擎能力对比（2026-11-18 实测）**

| 引擎 | 中文发现 | 国际英文 | 正文抓取 | 独立日期 | 成本 |
|---|---|---|---|---|---|
| **wb2a** | ★★★ | ★（中文转述） | ★★★ 免费 | 需 DSH UA，值可能为 null | 免费 |
| **Exa** | ★★ | ★★★ 权威原站 | ★★ | 有 | \$4/1k 搜索、\$1/1k 页 |
| **Tavily** | ★ | ★★★ 通讯社+精确时间 | ★ 仅摘要 | 有 GMT 时间 | 1–2 credits/次 |
| **Firecrawl** | — | — | ★★★ 硬反爬唯一解 | — | 1 credit/页 |

**成本 / 速度护栏**

- 发现阶段每期中文线 2 家 + 国际线 2 家即可，**勿四家全开**
- 正文能免费就免费（wb2a `--fetch`），Firecrawl 只在硬反爬出场
- ⛔ 不用 Firecrawl 试错 URL（403/404 照样扣费）、不整站 `/crawl`
- 关键数字至少双源；普通条目单源即可

> 📌 **一条重要经验**：把分工写成一致的"信号"比写成硬约束更有效。文档中自相矛盾的表述（旧版曾同时写"wb2a 是全球主力"和"wb2a 国际仅补充"）会让执行模型偏向免费万能的引擎。v4.0 已清理矛盾，实测三轮均自然收敛到正确分工。

## 🔧 安装

**环境要求**

- QwenPaw / Hermes Agent（支持 Skill 工具）
- 四引擎接入（按你实际拥有的配置，并非四家都必须）：
  - **wb2a / Exa / Tavily / Firecrawl** 的脚本或 MCP 工具
  - wb2a 复用 `yaner` provider 的 API key，端点 `POST https://token.yaner.fun/v1/search` 与 `POST /v1/fetch`（透传腾讯 CodeBuddy agenttool，查询免费）
  - Exa / Tavily / Firecrawl 各自的 API key 走环境变量或 `config.yaml`，**不要提交明文**

```bash
# 将技能放入工作区
cp -r china-briefing <workspace>/skills/

# 私钥类配置只放本地，切勿提交
cp config.example.yaml config.yaml   # 然后填入自己的 key（已在 .gitignore 中排除）
```

## 🚀 使用

直接说出需求即可：

```
给我今天的全球简报
今天国内有什么大事
江川路街道最近有什么新动态
AI 行业最新动态
```

技能自动完成：
1. 判定地理尺度与搜索线（中文线 / 国际线）
2. 按四引擎矩阵调用检索（各守岗位、关键事实双源交叉）
3. 生成结构化简报
4. 执行质量门禁
5. 交付

## 📋 输出格式

- 📌 **核心结论** — 1–2 句总览（必填）
- 📌 **头条速报** — 3 条头条 + 点评（必填，每条事实+来源超链接+点评）
- 📌 **分类热点** — 2–4 大类（必填）
- 📌 **数据看板** — 关键数据（可选）
- 📌 **行动建议** — 优先级表格（必填）
- 📌 **时间窗口** — 诚实标注覆盖区间，不把多日内容伪装成"今日"

来源统一用 `[媒体名](URL)` 超链接，不贴裸网址；媒体名用中文译名。
